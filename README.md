# Annexe Junglinster

Ein 3D-Spiel für die 7e. Eine Woche in der Annexe, ein anonymer Account, Entscheidungen mit Folgen.
Dahinter steckt der Skills-Kurs REAL TALK (Jahr 1): Gefühle verstehen und regulieren, Gedanken prüfen,
Grenzen setzen, digitale Welt, Gruppendruck – gelernt durch Entscheidungen, nicht durch Erklärungen.

**Spielen:** `index.html` öffnen (oder die GitHub-Pages-Adresse dieses Repos). Läuft im Browser auf iPad, Computer und Handy.

## Was drin ist
| Datei | Wofür |
|---|---|
| `index.html` | Startseite mit Kurzanleitung |
| `lycee.html` | Das Spiel (eine Datei, läuft auch ohne Internet) |
| `lycee.webmanifest`, `lycee-sw.js`, `lycee-pwa/` | iPad-App: Symbol auf dem Home-Bildschirm, offline, automatische Updates |
| `LEHRPERSONEN.md` | Hinweise für den Unterricht |

## Datenschutz
- Keine Anmeldung, keine Werbung, keine Statistik, keine Verbindungen zu anderen Diensten.
- Spielstände und Resümees bleiben im Browser des Geräts. Geteilt wird nur, was jemand selbst teilt (AirDrop, Mail).
